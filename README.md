# Homebrew tap

Install [LaTeXShot](https://github.com/exploringtruth/latexshot) with Homebrew.

```sh
brew install --cask exploringtruth/tap/latexshot
```

Requires Apple silicon and macOS 14 or later. LaTeXShot v1.0.0 is ad-hoc signed
and unnotarized. [First-launch instructions](https://github.com/exploringtruth/latexshot#if-macos-blocks-the-app)
